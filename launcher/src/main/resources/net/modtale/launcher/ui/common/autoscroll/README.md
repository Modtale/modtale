The `pan_*.png` images are PNG conversions of Chromium's Windows autoscroll
cursor files in `ui/resources/cursors/`:
https://chromium.googlesource.com/chromium/src/+/refs/heads/main/ui/resources/cursors/

They are 32 × 32 RGBA images converted from the corresponding `.cur` files.
